# **App Name**: Local Lens UK

## Core Features:

- UK Town Map: Display a map of the UK with markers indicating towns with location data.
- Local Town Map: Show a map of Formby (or other selected town), with markers for individual locations. These maps are initially seeded from the database.
- Location Details: Display detailed information for a selected location, including name, description, and user comments.
- Suggest New Location: Allow users to suggest new locations by filling in a form with name, description, picture upload, and user comments.
- Submission Screening: Maintain a backend process to review, correct, and approve submitted locations before they are published to the live site.
- Content Moderation Tool: Employ an AI tool to analyze the descriptions of new location submissions for inappropriate or offensive content before maintainer review. Location suggestions with inappropriate content are flagged for immediate removal and not displayed to the site maintainer.

## Style Guidelines:

- Primary color: Desaturated violet (#946aa8) to convey local charm.
- Background color: Light pale violet (#f2edf4).
- Accent color: Deep red violet (#872b55) for highlighting interactive elements and calls to action.
- Body and headline font: 'PT Sans' sans-serif for its modern look.
- Code font: 'Source Code Pro' for displaying any code snippets.
- Use simple, clean icons to represent location categories on the maps.
- Use a grid-based layout for location details, ensuring readability and a clean user experience.
- Employ subtle transitions when loading map data or location details to create a smooth and engaging experience.
